# workflows/

## Purpose

Operational workflow specifications for every pipeline in the system, from a founder's first prompt through planning, coding, building, previewing, error recovery, deployment, git operations, and multi-agent orchestration.

## Scope

Nine workflow documents. Every workflow defines Trigger, Input, Output, Decision Gates, Human Approval Points, and Rollback Strategy.

## Future Content

Additional workflows (e.g. a Brand-level or multi-project workflow) may be added as Phase 1 usage surfaces new pipelines.
