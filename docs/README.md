# docs/

## Purpose

Houses product-level documentation for AI CEO Studio: the vision, the problem it solves, how success is measured, and who it's for. It also houses the Phase 0 validation and freeze reports under docs/reports/.

## Scope

Product framing and repository governance reports. Does not contain architecture, workflow, or engineering specs — those live in architecture/, workflows/, and specs/ respectively.

## Future Content

docs/reports/ will grow with each phase's validation and freeze reports. A docs/roadmap/ folder may be added once Phase 1 milestones are defined.
