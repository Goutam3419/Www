# docs/reports/

## Purpose

Holds point-in-time governance artifacts: validation reports and phase-freeze confirmations that certify a phase is complete before the next one starts.

## Scope

Phase0-Validation-Report.md and PHASE0_FREEZE.md for this phase. Does not contain ongoing documentation — those live in their normal homes (architecture/, workflows/, etc.) and are only referenced from here.

## Future Content

Phase1-Validation-Report.md and a corresponding PHASE1_FREEZE.md once Phase 1 reaches its own definition of done.
