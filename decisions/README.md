# decisions/

## Purpose

Architecture Decision Records (ADRs) — the durable log of why the locked tech stack and key structural choices were made.

## Scope

Five ADRs covering monorepo structure, React 19, FastAPI, LangGraph, and Supabase. Format: Context, Decision, Consequences.

## Future Content

New ADRs are appended with the next sequential number as decisions are made; existing ADRs are never rewritten in place, only superseded by a new ADR that references them.
